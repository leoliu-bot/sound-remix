# 原作玩法与美术整理

整理日期：2026-09-10。研究范围为用户指定的 Steam app 3097330《共鸣 ReMix》。五个子 Agent 分批参与了玩法研究、美术研究、场景设计、战斗平衡与体验评审；实现与集成由主 Agent 完成。

## 已经找到官方依据的机制

1. **音乐节奏动作与 Roguelite 构筑**：不同英雄拥有不同音乐风格、节奏及技能，结合道具与角色能力进行战斗。商店列举了 Octavia 和 Amaya，以及十余位可招募乐手。
2. **乐队是核心**：队友按自身节拍执行节奏／旋律攻击。玩家跟随节拍调整队伍方向，可以释放更强力的音障。
3. **音乐随阵容叠加**：招募新的乐手后，相应乐器声部加入背景音乐。贝斯、吉他、提琴等乐器同时具有不同战斗能力。
4. **队伍成长与商店**：旧版官方公告包含购买、出售、合并、刷新、团队等级、道具等系统。冲锋和狙击敌人具有攻击指示。
5. **终极技能与校准**：开发团队采访介绍了终极技能及节奏校准等功能。

## 美术观察

根据直接查看的 Steam 官方截图，原作采用俯视像素表现，街道方向接近画面横竖轴线；建筑同时显示屋顶和朝下的店面。夜色中的柏油路、人行道、斑马线、暖色橱窗、蓝绿屋顶与树冠构成环境。玩家与队友是小型 Q 版像素人物，虚空敌人用深紫身体和暖红发光细节区分，音乐弹幕以电蓝、粉紫、音符与波纹为主。

## 本版本的取舍

保留乐队跟随、按拍自动演奏、转向音障、音乐声部叠加、随机成长和虚空敌人的身份特征。Three.js 将像素轮廓转成带明暗的体素角色，舞台设为被植被包围的霓光街区；配乐完全由 Web Audio 合成。

本版本采用自由移动、三选一升级、固定 150 秒首领出现时间，三名可选角色及数值均为本项目设计。没有实现原作完整格子移动规则、全部英雄、道具、剧情、商店买卖合并、自定义 MP3 导入与成就内容。没有使用原作专有美术、录音或代码。

## 评审修复

- 小屏及低高度菜单、弹窗可以滚动，开始与确认按钮保持可达。
- 暂停时冻结 AudioContext，不用平移逻辑事件来假装音频暂停。
- 长卡顿跳过过期音乐排程；切后台自动暂停。
- 暂停和升级同时冻结战斗预警特效，避免恢复后遭遇没有提示的攻击。
- 实例化绘制、实体数量上限与粒子清理降低绘制开销；不声称未实测的固定帧率。
